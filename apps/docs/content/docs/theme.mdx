title: Theme
description: Customize the design tokens used by every component in the registry.
---

Adjust the controls on the left and watch the preview on the right update instantly.
Editing **Primary** or **Background** re-derives the full palette, but every token —
including each chart color — is independently editable. The documentation UI itself is
never affected.

When you're happy with the result, use **Copy global.css** and **Copy theme.ts** to export
the generated tokens into `packages/library/reusables/global.css` and
`packages/library/reusables/lib/theme.ts`.
