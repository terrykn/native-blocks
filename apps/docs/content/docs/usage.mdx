## Using Native Blocks

Native Blocks is designed to be as flexible as possible. Once you've added a component using the CLI, it's yours. You can find the source code in your project's `components/ui` or `components/blocks` folder.

### Components vs Blocks

- **Components:** Atomic UI elements like Buttons, Inputs, and Badges.
- **Blocks:** More complex, pre-composed layouts like User Profiles, Settings Screens, and Account Setup flows.

### Customization

All Native Blocks components use NativeWind for styling. You can customize the look and feel by modifying the Tailwind classes in the component file.

```tsx
// Example customization
<Button className="bg-blue-500 rounded-full">
  <Text className="text-white font-bold">Custom Button</Text>
</Button>
```

### Working with React Native Reusables

Native Blocks is built to extend [React Native Reusables](https://reactnativereusables.com). Our custom theme styling works globally with all React Native Reusables components. If a component you need isn't in Native Blocks, you can add it from Reusables using their CLI or ours:

<BashCommand command={`npx native-blocks add <reusables-component>`} />

### Best Practices

- **Keep it Native:** Prioritize mobile-specific interactions and design patterns.
- **Stay Minimal:** Only add the components you actually need to keep your project clean.
- **Theme Support:** Native Blocks supports dark mode out of the box using NativeWind's color schemes.
