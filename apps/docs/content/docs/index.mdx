## Move faster with production-ready blocks and themes

Native Blocks is a registry distributed through shadcn/ui that provides premade, copy-paste React Native components and app blocks, with custom theme styling to match your branding.

Unlike traditional component libraries, Native Blocks gives you full control over the code. You can use the Native Blocks CLI to add components directly into your project and customize them to your needs.

### Features

- **Mobile-First:** Components designed for the native mobile experience.
- **Custom Theme Styling:** Copy & paste. Standardize across your application. Powered by NativeWind.
- **Smooth Animations:** Built with React Native Reanimated.
- **Copy & Paste:** No complex dependencies, just the code you need.

<Callout type="warn">
  Native Blocks currently uses NativeWind v4. For Tailwind v4, we will update once NativeWind v5 is stable.
</Callout>

## Documentation

Native Blocks is built to extend the amazing work by [React Native Reusables](https://reactnativereusables.com). 
Our blocks and custom theme styling are designed to be compatible with the existing Reusables ecosystem.
