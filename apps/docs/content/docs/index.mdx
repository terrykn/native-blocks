## Move faster with production-ready React Native blocks and custom themes

Native Blocks is a component registry that provides production-ready, copy-paste React Native components and app blocks. 

Unlike traditional component libraries, Native Blocks gives you full control over the code. You can use the Native Blocks CLI to add components directly into your project, where you can customize them to fit your specific needs.

### Features

- **Touch-First:** Components designed specifically for mobile interactions.
- **Custom Theme Styling:** Powered by NativeWind (Tailwind CSS for React Native).
- **Smooth Animations:** Built with React Native Reanimated.
- **Copy & Paste:** No complex dependencies, just the code you need.

<Callout type="warn">
  Native Blocks currently uses NativeWind v4. For Tailwind v4, we will update once NativeWind v5 is stable.
</Callout>

## Documentation

Native Blocks is built on top of the excellent work by [React Native Reusables](https://reactnativereusables.com). 
Our blocks and custom theme styling is designed to be compatible with the existing Reusables ecosystem.
