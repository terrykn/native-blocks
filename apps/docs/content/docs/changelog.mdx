## June 2026 - Initial Release

Native Blocks is available! A mobile-first React Native registry with global theme customization for components and a diverse library of blocks.

- 🚀 Initial set of components and blocks.
- 📦 shadcn/ui inspired CLI for easy installation and initialization.
- 📱 Mobile-first design patterns.
- 🎨 NativeWind v4 support.
